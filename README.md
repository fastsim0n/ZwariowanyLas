# 🌲 Zwariowany Las

**Zwariowany Las** to aplikacja edukacyjna dla dzieci, której celem jest ułatwienie nauki zagadnień związanych z przyrodą w przystępny i angażujący sposób.

Aplikacja może pomagać najmłodszym m.in. w **rozpoznawaniu gatunków drzew** oraz poznawaniu świata roślin i przyrody poprzez interaktywną naukę.

## 📋 Wymagania

Do uruchomienia projektu potrzebujesz:

- **Python w wersji niższej niż 3.13**
- `pip`
- `git`

Możesz sprawdzić zainstalowaną wersję Pythona poleceniem:

```bash
python --version
```

## 🚀 Instalacja i uruchomienie

### 1. Sklonuj repozytorium

```bash
git clone https://github.com/fastsim0n/ZwariowanyLas.git
```

Następnie przejdź do katalogu projektu:

```bash
cd ZwariowanyLas
```

### 2. Utwórz środowisko wirtualne

Zalecane jest korzystanie ze środowiska wirtualnego.

```bash
python -m venv venv
```

Aktywacja środowiska:

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 3. Zainstaluj wymagane biblioteki

```bash
pip install -r requirements.txt
```

### 4. Uruchom aplikację

```bash
python main.py
```
